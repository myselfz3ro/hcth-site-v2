# HCTH "Proper" Site v2

## Design Philosophy
- **High-Conversion:** Immediate booking friction reduction (WhatsApp/Form).
- **Mobile-First:** 95% of diners arrive on mobile via Google Maps/Ads.
- **Brand Identity:** High-end, warm, authentic (Nepalese/Tandoor).
- **SEO-First:** Schema markup, fast load, consistent NAP (Name, Address, Phone).

## Structure
- `index.html`: Hero, Booking CTA, Featured Dishes (Momo), Reviews (4.9/276), About (Chef/Origin), Maps/Location.
- `css/main.css`: Clean, minimalist, responsive design.
- `assets/`: Optimized images (momo, tandoor, restaurant).
